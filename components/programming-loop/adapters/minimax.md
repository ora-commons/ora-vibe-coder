# MiniMax Code adapter

Use this adapter only when MiniMax Code coordinates Programming Loop. The
universal framework remains the source of workflow truth.

## Fresh workers

Use a separate stateless one-shot task for each executor and reviewer. Put the
complete task-local packet in every call and require the complete result in the
response. Never use the executor response as the review context.

Treat the reviewer as advisory until its independent access is established.
Where the host cannot give a reviewer the repository, cumulative diff, and
authorized check evidence, return the criterion as unverified rather than
claiming `DONE`.

## Permissions and completion

A "smart" or automatic permission mode is not a sandbox. State prohibited
effects in every assignment and inspect the resulting working tree. Use a
bounded foreground call; do not detach a poller or infer completion from a
process exit without the returned content.

This adapter defines a plausible native route, not a claim of live end-to-end
qualification for every MiniMax Code release. Do not switch providers or incur
paid use without explicit authority.
