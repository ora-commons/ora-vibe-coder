# Programming Loop

Read `../../frameworks/programming-loop.md` completely, then read exactly one
file from `../../adapters/`: the adapter matching the host that is initiating
and coordinating this run.

Apply the universal framework as the method and the selected adapter only as
the mapping to native worker, result, and wait operations. Do not load every
adapter, substitute an adapter for a review target, or infer authority to call a
provider. If either required file is unavailable, identify the missing file and
stop rather than approximating the method.
