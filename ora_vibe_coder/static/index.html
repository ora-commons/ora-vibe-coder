Choose the folder where you keep your projects. Opening a folder does not create or change a project. You can then open existing work or deliberately create a new project.

Working with Vibe Coder

Choose a project, then select any of the four stages. Link existing documents to their roles using Link documents / edit; missing links and missing files are different things.

Write your next instruction and choose a coding tool. Prepare request saves and shows the complete Markdown assignment. Continue requests a normal interactive conversation in that coding tool. Its login, project rules, and approval steps still apply. Copy is available for manual delivery.

Return to this page and use Refresh files to read saved work. Status labels report fields in your documents; opening a window does not mark a stage complete. Later source changes require Prepare Again.

Drafts stay in this browser tab while switching projects or stages. Keep the tab open until you have saved or copied your input. Closing the tab does not stop the local process. Use Stop app when finished; reopen Ora Vibe Coder from its launcher.

New project

Creates one new directory and Project.md only. Existing files are never replaced.

Open existing project

This selects an existing directory. Link its documents explicitly; no files are renamed or overwritten. Projects directly inside your selected projects folder appear automatically next time; use Open existing again for other locations.

Project information and document links

Only the overview and associations are edited. Stage documents and reported results stay untouched. Simultaneous overview edits are unsupported.
